## 1. Конструктор выстрела

Выстрел — обычная активируемая способность, но собирать её каждый раз вручную долго. Поэтому в `AbilitiesData` есть метод-конструктор:

```csharp
Shot("ability_shot_archer", damage: 3, distance: 2, ammo: 10),
Shot("ability_shot_peasant", damage: 3, distance: 1, ammo: 3),
// Выстрел за ману и с бесконечным боезапасом:
Shot("ability_shot_x", damage: 2, distance: 0, cost: [new ManaCost(1, ManaType.Fire)]),
```

`cost` и `ammo` — **необязательные параметры** (`= null`): не указал — выстрел бесплатный и бесконечный. **Именованные аргументы** (`damage: 3`) читаются как описание карты и не дают перепутать урон с дистанцией.

Конструктор сам делает название («Выстрел (урон 3, дистанция 2, боезапас 10)»), включает поворот (`ActivationTapsSelf`), выбор цели (`ShotTarget`) и условие «фаза атаки своего хода, боезапас не кончился».

Как работает выстрел:
- В окне существа кнопка «Активировать: Выстрел…», потом клик по вражескому существу в пределах дистанции.
- Урон = урон выстрела − блок цели. В ответ урона нет.
- Боезапас хранится в самой карте (`Card.AmmoLeft`), остаток виден в описании.

## 2. Новые свойства

| Свойство | Где в коде |
|---|---|
| **Первый удар** — убил в схватке, урона не получил; у обоих — не действует | `ResolveFights` |
| **Миг** — существо можно разыграть в любую фазу | `CanDrag` |
| **Оглушение** — поворот, пропуск разворотов в своё снабжение, способности не работают | `Stun`, `UntapAll`, `CanActivate` |
| «Когда убивает» (Крестьянка) | `AbilityData.OnKill`, вызывается в `CleanupDead` |
| «Когда получает урон» (Хива) | `AbilityData.OnDamaged`, вызывается в `ApplyDamage` |
| «Новая линия» (Фонарщик) | `AbilityData.OnEnterNewLane`, вызывается в `PlaceOnLane` |
| «Когда существо развернётся» (Безмятежное видение) | `AbilityData.OnHostUntapped`, вызывается в `UntapAll` |

**Один вход для урона и перемещения.** Чтобы «когда получает урон» и «новая линия» срабатывали всегда, весь урон существам теперь идёт через `ApplyDamage`, а все перемещения на линию через `PlaceOnLane`. Это частый приём: если событие должно ловиться везде, у него должно быть одно место, через которое оно проходит.

## 3. Оплата

- **Варианты цены** («2 золота или 1 вера»): `AlternativeCosts`. Если можно заплатить несколькими способами, игра спрашивает, каким.
- **Сброс карты в оплату** (Фари, Трюк пиромана): в окне оплаты кликаешь по картам в руке, выбранные подсвечиваются. Сбрасываются только когда оплата закончена, при отмене остаются в руке.
- **Цена X** («Выпить любой ценой»): каждый клик по мане, по карте в руке или по своему существу даёт +1, потом «Готово».
- **Скидка Зомби:** при розыгрыше появляется окно со существами из твоего сброса, выбираешь от 0 до 2. Изгнанные исчезают из игры.
- **Енот грабитель:** если в этом ходу умерло любое существо, он бесплатный и разыгрывается ещё и на линии, где умирали существа.

## 4. Окно выбора и async-эффекты

`ChoiceView.Ask(...)` показывает кнопки и возвращает `Task<int>`. Эффекты, которым нужен ответ игрока, написаны как `async`-лямбды:

```csharp
OnHostUntapped = async ctx =>
{
	int choice = await ctx.Battle.ChooseAsync(owner, "Что получить?", ["2 тьмы", "2 света"]);
	...
	ctx.Battle.AfterAsyncEffect(); // эффект доиграл позже обычного — обновить экран и убрать погибших
},
```

Если вопросов несколько сразу (две «Зависимости» в одних трофеях), `ChoiceView` показывает их по очереди.

## 6. Термины «Любая» и «Элементальная»

В цене теперь пишется «4 Любых» и «6 Элементальных» вместо длинного списка типов. `ManaCost` сам узнаёт такие наборы (`IsAny`, `IsElemental`): сравнивает свои типы с `ManaTypeExtensions.AllTypes` и `ElementalTypes` как множества, порядок не важен. Если такое слово есть в цене карты, в цене альтернативы, в цене активации или «Лени», справа в «Пояснениях» появляется его объяснение.

## Поправки по терминологии

- **«Конструктор»** в C# — это метод `new Класс(...)`, который создаёт объект. Здесь у нас **фабричный метод** (factory method): обычный статический метод `Shot(...)`, который собирает и возвращает готовый `AbilityData`. Смысл тот же — «удобный способ создать», но слово «конструктор» в C# занято.
- **«Мясо»** в коде — еда (`ManaType.Food`).
- **«Удалить из сброса»** в карточных играх обычно называют **изгнанием** (exile): карта уходит из игры совсем.
- **«Пожертвовать»** — sacrifice: своё существо уходит в сброс как оплата.
